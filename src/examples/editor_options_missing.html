Editor options - the Missing selector behaviour

showSelectedVariants and showSelectedPrintOptions live in the editorOptions block at the root of the editor arguments. They decide whether the editor asks the user to pick variants / print options, or silently uses what the integration sent.

Value showSelectedVariants showSelectedPrintOptions
None Dialog is not shown when variants are specified. Dialog is not shown when print options are specified.
Selected Only variants provided in arguments are shown; the user can remove them but cannot add new ones. Only print options provided in arguments are shown; the user can remove them but cannot add new ones.
Missing The variant selector is shown only when one or more provided variants are not found. The user can then remove or add any product variant. The print option selector is shown only when one or more provided print options are not found.
All The variant selector is always shown with all product variants; the provided ones are preselected. The print option selector is always shown with all print options; the provided ones are preselected.

Missing is the safety net for catalogue drift: as long as every code your shop sends still exists, the user goes straight into the design. As soon as a code disappears - a discontinued colour, a renamed print position - the editor falls back to a selector instead of failing or quietly dropping the item.

Note: the documentation marks Missing as Coming Soon. On an instance where it is not deployed yet, the editor may fall back to its default behaviour - compare with the other values using the switches below.

All five scenarios use the same Teak notebook (PFC) with 3 variants and 2 printings. Wrong codes are marked with an XX suffix so they cannot be found in the catalogue. Every button opens a new print job in Create mode.

Implementation

Editor arguments with Missing

window.tronDesigner.openDesigner({
    openMode: "Create",
    dataMode: "Exact",
    editorOptions: {
        showSelectedVariants: "Missing",      // None | Selected | Missing | All
        showSelectedPrintOptions: "Missing"   // None | Selected | Missing | All
    },
    printJob: {
        addPrintings: [
            { printPositionCode: "front", printTechnologyCode: "GPE01" },
            { printPositionCode: "back",  printTechnologyCode: "GPE01" }
        ],
        addProducts: {
            supplierCode: "PFC",
            variants: [
                { productCode: "10601321" },   // red
                { productCode: "10601301" },   // white
                { productCode: "10601331" }    // orange
            ]
        }
    }
}, { mode: "dialog" });

Scenario 2 - variant codes that no longer exist

variants: [
    { productCode: "10601321" },     // found
    { productCode: "10601301XX" },   // not found -> triggers the variant selector
    { productCode: "10601331XX" }    // not found
]

Scenarios 3 and 4 - print positions that no longer exist

// one printing wrong -> selector opens, "front" stays preselected
addPrintings: [
    { printPositionCode: "front",  printTechnologyCode: "GPE01" },
    { printPositionCode: "backXX", printTechnologyCode: "GPE01" }
]

// both printings wrong -> selector opens with nothing preselected
addPrintings: [
    { printPositionCode: "frontXX", printTechnologyCode: "GPE01" },
    { printPositionCode: "backXX",  printTechnologyCode: "GPE01" }
]

Scenario 5 - one variant and one printing missing

// both options are evaluated independently -> both selectors open
addProducts: {
    supplierCode: "PFC",
    variants: [
        { productCode: "10601321" },     // found
        { productCode: "10601301" },     // found
        { productCode: "10601331XX" }    // not found -> variant selector
    ]
},
addPrintings: [
    { printPositionCode: "front",  printTechnologyCode: "GPE01" },   // found
    { printPositionCode: "backXX", printTechnologyCode: "GPE01" }    // not found -> print option selector
]

Same options with the JS builder

const td = window.tronDesigner;

td.setExactProduct("PFC", undefined, (b) => {
    b.addVariant("10601321");
    b.addVariant("10601301");
    b.addVariant("10601331");
});
td.addExactPrinting("front", "GPE01");
td.addExactPrinting("back", "GPE01");

td.argsBuilder.setEditorOptions({
    showSelectedVariants: "Missing",
    showSelectedPrintOptions: "Missing"
});

td.open({ mode: "dialog" });

If editorOptions is omitted entirely, the SDK sends { showSelectedVariants: "None", showSelectedPrintOptions: "None" } - the same applies to each of the two keys individually.
